AttentionX

An attention intelligence project for e-learning, bringing gaze, posture, and behavioral signals together into interpretable learner indices.

OpenCVMediaPipeYOLOv8PyTorch
Explore the case study

The problem

Individual webcam cues offer an incomplete view of learner engagement. The project explores how several signals can be combined into a more useful attention estimate.

My contribution

  • Built a computer vision pipeline using gaze, head posture, and facial cues.
  • Combined visual signals with behavioral events and weighted scoring logic.
  • Developed attention and engagement indices, with evaluation against manual labels.

Reported project evaluation

The academic project reported 92.8% attention fluctuation accuracy and latency below 200 ms.

These are project evaluation results, specific to the recorded setup and labels.

What I learned

Signal quality, evaluation labels, and the interpretation of a score matter as much as the model itself.

LiverGuard

A team research project exploring clinical data analysis, liver disease classification, and a CT-scan deep learning pipeline during the NUS Global Academic Internship.

PythonEDAscikit-learnResNet-50
Explore the case study

The problem

Explore patterns in clinical features and compare classification approaches, alongside analysis of a CT-scan segmentation and detection pipeline.

My contribution

  • Conducted EDA on 16,389 patient records and analyzed relationships between clinical features.
  • Evaluated Random Forest, Decision Tree, and KNN approaches and contributed to ensemble evaluation.
  • Analyzed and optimized ResNet-50 preprocessing, including normalization and contrast enhancement.

Reported project evaluation

The project reported 99.91% ensemble classification accuracy in its academic evaluation.

This is a reported academic result. Clinical suitability and external validation were outside the scope of this portfolio evidence.

What I learned

Preprocessing and feature analysis must be understood alongside model metrics and the limits of the evaluation.

04 / Academic projectComputer vision

Tennis Analysis System

A computer vision pipeline for player and ball detection, court keypoint extraction, and spatial analysis of match footage.

YOLOv8PyTorchCNNHomography
Explore the case study

The problem

Translate match video into useful spatial information by connecting object detection with court geometry.

My contribution

  • Developed player and ball detection with a custom CNN for 14 court keypoints.
  • Applied keypoint refinement and homography correction.
  • Trained and validated with 8,841 annotated tournament-video frames.

Reported project evaluation

Precision improved from 0.936 to 0.963; median keypoint error reduced from 2.83 to 1.83 pixels in the project evaluation.

What I learned

Combining classical computer vision with learned models can improve the quality of the final analytical output.
